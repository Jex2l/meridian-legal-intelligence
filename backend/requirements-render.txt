# Lean requirements for the Render (free tier) deployment -- same as
# requirements.txt but WITHOUT sentence-transformers, which transitively
# pulls in torch + transformers + numpy + scipy + scikit-learn. Confirmed
# live: that combination exceeds a 512MB host's RAM just loading two small
# models at startup.
#
# This is safe only because production is configured to not need those
# models at all: EMBEDDING_PROVIDER=huggingface_api (calls HF's hosted API
# instead of loading a local model, see app/retrieval/embedding.py) and
# ENABLE_RERANKER=false (the cross-encoder reranker has no remote
# equivalent here, so it's simply disabled in production -- hybrid_search()
# falls back to the RRF fused score for ranking and the confidence gate,
# see app/retrieval/search.py and app/generation/confidence.py). If either
# of those env vars isn't set correctly, the app will try to import
# sentence_transformers and fail with ModuleNotFoundError -- that's the
# intended, loud failure mode rather than silently reinstalling the heavy
# dependency.
#
# Local development should keep using plain requirements.txt, which keeps
# sentence-transformers so the full test suite (including the parts that
# exercise real model behavior, not mocks) keeps working unchanged.
